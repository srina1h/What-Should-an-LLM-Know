# PromiseTune PostgreSQL benchmark provenance

The PromiseTune repository lists PostgreSQL among its configuration systems
and labels its benchmark PolePosition 0.6.0 with runtime in milliseconds.
Its catalog is a provenance lead for the MOOT task, not a verified row-by-row
mapping to this frozen CSV. In particular, its displayed version field should
not be used to assign a PostgreSQL release to the MOOT export without checking
the original dataset construction records. No performance values or favored
settings from PromiseTune are included in this retrieval note.

# MOOT project-health task

MOOT describes the Health family as tuning random-forest regression models to
predict open-source project activity over the following twelve months. The
outcomes cover commits, closed issues, or closed pull requests, depending on
the dataset. `Health-ClosedIssues0001` belongs to the closed-issues family.
The description establishes the task and learner family; it does not decode
every feature value or give a formula for this export's `ACC+` objective.
